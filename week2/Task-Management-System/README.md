# Task Management System

## Overview

The Task Management System is a simple Node.js application that helps users manage tasks efficiently. This project demonstrates the use of JavaScript modules, validation techniques, and task handling operations.

The application is designed for beginners learning backend JavaScript concepts and modular programming.

---



# File Descriptions

## 1. app.js

This is the main entry point of the application.

### Responsibilities

* Runs the application
* Connects all modules together
* Handles execution flow
* Calls task management functions

### Concepts Used

* Module Import/Export
* Function Calls
* Application Flow Control

---

## 2. task.js

Contains the logic related to task operations.

### Functionalities

* Add Tasks
* Update Tasks
* Delete Tasks
* Display Tasks
* Manage Task Data

### Concepts Used

* Arrays
* Objects
* Functions
* CRUD Operations

---

## 3. validator.js

Handles validation of task inputs.

### Responsibilities

* Validate task names
* Check empty values
* Ensure correct data format
* Prevent invalid task entries

### Concepts Used

* Conditional Statements
* Input Validation
* Error Handling

---
