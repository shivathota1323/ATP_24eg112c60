# Backend1 Node.js API Project

## Overview

Backend1 is a simple Node.js backend application designed to demonstrate the fundamentals of server-side development using JavaScript and Node.js.

This project includes:

* Basic server setup
* API request handling
* REST client testing using `.http` files
* Node.js package management

The project is suitable for beginners learning backend development and API creation.



# File Descriptions

## 1. server.js

This is the main backend server file.

### Responsibilities

* Creates and runs the server
* Handles API routes
* Sends responses to client requests
* Manages backend logic

### Concepts Used

* Node.js
* HTTP Server
* REST API Basics
* Routing

---

## 2. req.http

This file is used for testing API endpoints directly inside VS Code using the REST Client extension.

### Features

* Send GET requests
* Send POST requests
* Test API responses
* Debug endpoints easily

### Recommended Extension

Install the following VS Code extension:

* REST Client by Huachao Mao

---

## 3. package.json

Contains project metadata and dependency information.

### Includes

* Project name
* Scripts
* Dependencies
* Version details

## 4. package-lock.json

Automatically generated file used to lock dependency versions.

### Purpose
